# Basic NumPy Example

This repository is a sample for verifying integration with OpenAI Codex.
このリポジトリは OpenAI Codex との連携検証を目的としたサンプルです。

This repository contains a small Jupyter Notebook demonstrating the basics of
using NumPy.

## Requirements

- Python 3
- NumPy

Install NumPy with:

```bash
pip install numpy
```

Open the notebook with Jupyter:

```bash
jupyter notebook numpy_basic.ipynb
```

This will display simple operations such as array creation, arithmetic, and reshaping.
